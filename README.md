# Sai's Professional Learning Portfolio

A responsive GitHub Pages portfolio for course-based artifacts. The first artifact is a visual framework covering ten machine learning algorithms.

## Local preview

Open `index.html` in a browser.

## Publish with GitHub Pages

This repository includes a GitHub Actions workflow in `.github/workflows/pages.yml`. In the repository's **Settings → Pages**, select **GitHub Actions** as the build and deployment source. The workflow publishes the site when changes are pushed to `main`.

## Update the portfolio

- Edit `index.html` to update the bio, value proposition, or artifact descriptions.
- Add future course work under `artifacts/` and link it from the artifacts section.
- Keep artifact information together with the deliverable: title, objective, process, tools, and value proposition.
